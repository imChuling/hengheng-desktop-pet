Where to find the file

If you made a pet in Codex, look for its spritesheet.webp file in your Codex pets folder. On macOS/Linux, try ~/.codex/pets/<pet-name>/spritesheet.webp. On Windows, try %USERPROFILE%\.codex\pets\<pet-name>\spritesheet.webp.

You can also download a Codex pet package from community sites like petdex.crafter.run, codexpets.net/gallery, or codex-pets.net. Unzip the package, then choose its spritesheet.webp file.

About Pet Manager

Manage local desktop pets, preview their states, and import Codex-compatible spritesheets.

Codex pet format

Imports use one spritesheet.webp with 9 rows in this order: idle, running-right, running-left, waving, jumping, failed, waiting, running, and review. Each cell is 192x208.

Behavior controls

Behavior selects the animation state. Auto Motion only moves the pet around its home position while Behavior is set to Default.
